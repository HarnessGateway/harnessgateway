# Scoping a statement of work

Write `statement-of-work.md` in the working folder, with these parts, in this order:

1. **Outcome**: what the client has when the work is done, in one sentence.
2. **In scope**: each deliverable, as something that can be checked.
3. **Out of scope**: what a reader might assume is included, and is not.
4. **Assumptions**: what must be true for the estimate to hold, and who owns each.
5. **Approach**: the phases, each with what it produces.
6. **Estimate**: days for each phase, as a range, and what would move it.
7. **Risks**: each with what would be done about it.

Ask for what is missing before estimating. Never give one number where a range is the truth.
